# AGENTS.md

## Project expectations
- This is a static Vite + React + TypeScript app.
- Keep dependencies minimal.
- Do not add a backend, database, auth, or editing UI unless explicitly requested.
- Event data must remain JSON-driven.
- The app must support GitHub Pages and nginx static hosting.
- Use clean, readable TypeScript.
- Handle incomplete event data safely.
- Run `npm run build` before considering the task complete.
